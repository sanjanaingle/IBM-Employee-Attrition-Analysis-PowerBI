# IBM Employee Attrition Analysis Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze employee attrition and identify patterns across different employee characteristics.

The dashboard provides management with an overview of employee turnover and allows users to explore attrition across departments, job roles, age groups, gender, overtime status, and education fields.

## 🎯 Objectives

- Analyze overall employee attrition
- Identify departments with higher attrition
- Analyze attrition by job role
- Understand attrition across different age groups
- Compare male and female employee attrition
- Analyze the relationship between overtime and attrition
- Examine attrition across education fields
- Provide an interactive dashboard for business analysis

## 📌 Key KPIs

- Total Employees
- Employees Left
- Attrition Rate %

## 📈 Dashboard Analysis

The dashboard includes analysis of:

- Department-wise Attrition
- Job Role-wise Attrition
- Age Group-wise Attrition
- Gender-wise Attrition
- Overtime vs. Attrition
- Education Field-wise Attrition
